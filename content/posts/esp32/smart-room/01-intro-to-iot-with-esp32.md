## Overview

This is the start of my learning journey into the Internet of Things (IoT), microcontrollers and connected devices, using the ESP32.

My goal was to understand how hardware components interact, how sensors collect information, and how a microcontroller turns those inputs into meaningful outputs.

I combined theory with hands-on experimentation in Wokwi simulations, using a smart room occupancy system as a practical example.

## What I did

- Explored IoT concepts, applications and real-world use cases.
- Studied the ESP32 microcontroller and its GPIO pins.
- Learned how to connect and interact with electronic components.
- Experimented with a PIR motion sensor, an LED and an OLED display.
- Built a smart room occupancy monitoring system, with motion detection and occupancy status updates.
- Added time-based logic to decide when a room should be marked vacant.
- Simulated and tested everything in Wokwi.

## What I learnt

- How IoT systems combine hardware, software and connectivity.
- How a microcontroller communicates with electronic components through GPIO pins.
- How PIR sensors detect motion, and how sensor inputs can trigger different outputs.
- How to structure a basic embedded program.
- How to troubleshoot both hardware configurations and software logic.
- How simulation supports learning and prototyping before you build anything physical.
